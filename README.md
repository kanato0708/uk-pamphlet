# 宇工祭2026 デジタルパンフレット

## ファイル構成
- `index.html` … 表紙
- `saiji.html` … 催事一覧・検索・混雑状況
- `map.html` / `map.png` … タップできる校内マップ
- `events.json` … 初回公開と通信できないときに使う予備データ。同じ催事の `id` は変更しない
- `event-data.js` … 公開中の催事データをFirestoreから読み込み、管理者の更新を保存する
- `admin.html` … 生徒会役員用トップ。混雑状況管理と同じ管理者アカウントでログインする
- `map-links.json` … 地図番号・体育館と催事IDの対応
- `map-positions.json` … 地図上のボタンの位置（画像に対する百分率）
- `map-local-data.js` … ファイルを直接開いたときに使う予備データ
- `manifest.json` / `sw.js` / `icon-192.png` / `icon-512.png` … ホーム画面追加・オフライン対応用

## 催事データ
公開中の催事データはFirestoreの `siteContent/events` と `publishedEvents` に保存します。`events.json` は初回公開時と通信できないときの予備データです。

```json
"3f": {
  "label": "3階",
  "building": "校舎",
  "items": [
    { "name": "催し物名", "room": "教室", "time": "9:00-15:00", "desc": "説明文（省略可）" }
  ]
}
```

## ブラウザで催事を編集する方法
1. 表紙の「生徒会役員の方はこちら」からログインし、「催事を編集」を開く。公開サイト上なら現在の催事データが自動で読み込まれる
2. 催事名・カテゴリ・場所・時間・説明を編集する。写真は「写真を選ぶ」から指定する（追加・削除も可能）
3. 「更新して公開」を押す。保存が完了すると来場者向けページに反映される

写真は自動で縮小してFirestoreに保存します。催事を追加した場合は混雑状況管理ページの「未登録の催事を登録」も実行してください。翌年度は公開中のデータを画面で更新できます。地図や混雑状況との対応に使うため、既存催事の `id` は維持されます。

管理者トップには Firebase Authentication のメール・パスワードと、Firestore の `users/{uid}` に設定した有効な `admin` 権限が必要です。係（`staff`）は混雑状況更新ページだけを利用できます。Firestoreの `firestore.rules` をFirebaseコンソールへ反映してから更新機能を利用してください。静的な GitHub Pages では HTML ファイルや予備の `events.json` 自体の閲覧をサーバー側で制限できません。

## 公開手順（GitHub Pages / 無料・HTTPS対応）
1. GitHubで新しいリポジトリを作成（例: `ukousai-2026`）
2. このフォルダ内の公開用ファイルをまとめてアップロード（またはgit push）
3. リポジトリの Settings → Pages → Branch を `main` / `/root` に設定して保存
4. 数分後 `https://ユーザー名.github.io/ukousai-2026/` でアクセス可能に
5. QRコードを生成してポスターや来場者受付に掲示
6. iPhoneはSafari共有→「ホーム画面に追加」、AndroidはChromeで開くと自動でインストール提案が出ます

## 校内マップの調整
`map-links.json` の番号に催事の `id` を指定します。33番のように同じ場所で複数の催事がある場合は、配列に両方のIDを入れます。
`map-positions.json` の `x` と `y` は、地図画像の左上を0、右下を100としたボタンの位置です。
公開サイトではFirestoreの催事データを読み込みます。`map.html` をファイルとして直接開いた場合は `map-local-data.js` の予備データを使うため、催事データを変更した後の確認は公開サイトで行ってください。
